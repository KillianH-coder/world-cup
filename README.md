# world-cup

A simple go program to simulate a world cup.

# How to make it work ?

You need to use the command `go run .` in the root directory.

*the result will be displayed in the ***leaderboard.txt*** and the ***scoreboard.txt file*** *

## Depedencies

All you need is go 1.26.1 or a newer version.

#### What does the terminal display ?

It's just to track if everything is ok.

> It's not needed though.
